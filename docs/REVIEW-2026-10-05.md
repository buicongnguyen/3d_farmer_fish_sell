# Remaining-work review — 2026-10-05

This review follows the deployed village handoff (`c1ab0d2`) and examines the concrete defects in Claude's [remaining-work notes](REMAINING-WORK.md), plus related save, movement and rendering logic. The older notes remain as history; the fixes below supersede their matching issue descriptions. Feature redesigns remain separate.

## Code fixes in this pass

| Area | Finding and resulting behavior |
| --- | --- |
| Old fruit-tree saves | A removed planting spot previously discarded a mature tree in exchange for its sapling price. Displaced trees now move to an available safe spot, preferring existing stumps, while retaining age and last harvest. Surviving tree IDs stay unchanged. Capacity overflow receives a one-time full sapling refund. |
| Save imports | Replacing state in a running world left old simulations alive. Import now validates and stores the replacement, then reloads the world. Cancellation or storage failure preserves the current story and permits selecting the same file again. |
| Save validation | Inherited names such as `constructor` could pass item, crop, tree or worker-job checks; an invalid worker could corrupt savings on the next morning. Parsing now accepts only defined content entries. Gear, look and collection parsing were also checked for these names. |
| Health and wardrobe | Removing health-boosting gear while paused retained excess health, allowing it to return on re-equipping. Buying, equipping, removing and loading gear now apply the current health maximum immediately. |
| Fish collections | The five new catchable species were classified as pantry items. Both basket groups and the collection log now use the pond's species pools. |
| Pond quality changes | A governor or quality change rebuilt the school, losing the hooked fish and landing animation. It now resizes the existing school, preserving active fish and removing duplicate species before unique ones. |
| Rendering resources | Pond upgrades now release retired fish geometry and instance buffers; merged temporary geometry is released. Reused storage removes several per-frame allocations in pond effects, outdoor fish and Night Land projection. This does not claim zero allocation or prove absence of all leaks. |
| Driving shadows | A late outfit download could restore shadows on every limb instead of just head/body. Replacement avatars now receive the same shadow policy. Driving retains nearby NPC shadows with a shorter distance range, avoiding distant detail in the wider view. |
| Driving tree detail | Round, blossom and pine trees use fitted simple geometry in the wider driving view, removing up to 40,504 triangles across the visible and shadow passes. Walking restores their exact full geometry. Tree positions, materials, cleared IDs and the added palm/swamp/jungle types stay intact. |
| Night Land and weather | Small screens receive a lighter darkness overlay and a minimum visible area around the player. Ember Fields weather announcements wait for the arrival greeting; damage warnings remain immediate. Falling weather clears when changing regions. |
| Music | Quality changes disconnect obsolete reverb inputs as well as outputs. A delayed audio resume cannot unmute music after it has been disabled or the tab hidden. |
| Villager movement | Pedestrians respect each other's and the player's space, try a side step when blocked, and can separate if already overlapping. Stepping aside for a vehicle also respects other pedestrians. |
| NPC motorbikes | Riders stop at occupied space instead of eventually creeping through it; movement is bounded when an obstacle enters the lane. Larger animals and the player's vehicle receive additional clearance. Opposing riders can pull aside on checked ground. A new day clears an unfinished previous-day ride. |
| Jeep recovery | Repeated collisions near a tree/building corner trigger a bounded escape route using vehicle clearance. Releasing or changing input cancels recovery. Reached or invalid waypoints cannot cause division by zero or invalid positions. |
| Outfits and portraits | Build width was applied twice to some clothing/gear; fitting now applies it once. Late portrait asset loads cannot overwrite the newly selected resident. Preview rendering restores the previous render target and clear state even after a failure. |
| Crop selection | Cached crop picking now accounts for camera movement, zoom, resize and camera replacement, preventing a repeated screen tap from selecting the previous bed. |
| Initial load | Debug helpers move into a separate chunk to leave space for fixes under the existing first-frame bundle limit. |

## Explicitly deferred

- Ring-shaped world redesign and its layout migration remain outside this bug-fix pass.
- Tree crops in garden beds, villager disguises, disguise skills and their drop table need separate content/combat decisions.
- Outfit icon presentation, preferred garment cuts/hems, crop/seed proportions and fish-model appearance remain visual choices; the concrete fitting and picking defects above are separate fixes.
- Physical-phone play and listening remain manual checks: Night Land, landscape home-room visibility, pond/crop/outfit readability, touch controls and music through a phone speaker. Browser emulation is not a claim of real-device verification.
- Long-session memory/thermal performance and the older full browser sweep remain unverified until explicitly recorded. NPC mid-ride reload still derives a parked bay from the clock; persisting ride progress would require a new save feature.
- `cute_game` online-play issues belong to the separate source repository and are not changed here.
